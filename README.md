# WorkLedger – prototyp

Jednoduchá česká PWA pro evidenci odpracovaného času, odběratelů a přehledu fakturačního období.

## Co umí
- Přidat odběratele a jeho hodinovou sazbu
- Zaznamenat datum, čas od/do, přestávku a popis práce
- Automaticky spočítat hodiny a částku
- Zobrazit souhrn za zvolené období
- Exportovat souhrn do CSV a zálohovat data do JSON

## Důležitá omezení
Data se ukládají pouze lokálně v prohlížeči tohoto zařízení. Nejsou synchronizována do cloudu. Prototyp nevystavuje faktury, nekomunikuje s Fakturyweb.cz a nepočítá daně. Před použitím pro skutečnou fakturaci si výstupy zkontrolujte.

## Nasazení
Nahrajte obsah složky na statický HTTPS hosting. Na iPhonu otevřete adresu v Safari a zvolte Sdílet → Přidat na plochu.
